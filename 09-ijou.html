N2文法09「～以上/ 以上は」既然是...、就必須/就應該...

【意味】

「～以上 / ～以上は」表示「既然是～，那麼就理所當然地～」的意思。它基於某個已確定的事實、立場、身分或前提，推導出後續理所當然應承擔的責任、義務、決心或結論。帶有「既然已經如此，就沒有回頭路了」的語感。

【解說】

這個文法常用來表達說話者對於某個情況所抱持的決心、責任感，或是根據某種狀況而必然會產生的結果。「～以上」和「～以上は」兩者意思相近，多數情況下可以互換使用。「以上は」語氣略強，更強調前項的條件或前提。

常見的後項搭配有：「～べきだ（應該）」、「～なければならない（必須）」、「～よう（吧、打算）」、「～だろう（吧）」、動詞的「～て当然だ（理所當然）」等。

  • 学生がくせいであるである以上、勉強べんきょうするのは当然とうぜんだ。
    （既然是學生，讀書就是理所當然的。）

【接續】

  • 動詞どうし：普通形ふつうけい ( 辞書形じしょけい / た形たけい ) + 以上 / 以上は
  • い形容詞けいようし：普通形ふつうけい + 以上 / 以上は
  • な形容詞けいようし：語幹ごかん + である + 以上 / 以上は
  • 名詞めいし：名詞めいし + である + 以上 / 以上は

【例文】

  • 学生がくせいであるである以上、勉強べんきょうするのは当然とうぜんだ。
    （既然是學生，讀書就是理所當然的。）
  • 一旦いったん引ひき受うけた以上は、責任せきにんを持もって最後さいごまでやり遂とげるべきだ。
    （既然已經承接了，就應該負責任地完成到最後。）
  • 会社かいしゃのルールに従したがう以上、その決定けっていには異議いぎを唱となえられない。
    （既然要遵守公司的規定，就不能對那項決定提出異議。）
  • 日本語にほんごを勉強べんきょうすると決きめた以上は、N1まで頑張がんばりたい。
    （既然決定要學習日文，就想努力到N1。）
  • 彼かれが来こないと言いう以上は、もう待まつ必要ひつようはないだろう。
    （既然他說不來，就沒有必要再等了吧。）

【易混淆文法比較】

「～以上/以上は」與「～からには」和「～からこそ」都含有「因為～所以～」的語氣，但在強調的重點和語感上有所差異。
