N2文法09「～以上 / ～以上は」既然...，就... / 只要是...，就...

【意味】

中文意思：既然...，就... / 只要是...，就...

【解說】

「～以上いじょう / ～以上いじょうは」是一種N2文法ぶんぽう，用於もち表示ひょうじ「既然きぜん某個條件じょうけん或事實じじつ成立せいりつ，那麼後續こうぞく的結果けっか、行動こうどう、判斷はんだん或義務ぎむ就是理所當然りしょとうぜん或必然ひつぜん的」。
它強調それきょうちょう在前項ぜんこう條件じょうけん成立せいりつ的前提ぜんてい下，後項こうこう內容ないようは不可避免ふかひめいです。後句こうくは義務ぎむ、決心けっしん、決定けってい、忠告ちゅうこくや判断はんだんといった語気ごきを伴ともうことが多おおいです。

この文法点ぶんぽうてんの語気ごきは比較的ひかくてきに客観的きゃっかんてきであり、既定きていの事実じじつやルールを述のべるようなものです。
例たとえば、「大人おとなである以上いじょう、責任せきにんを負おうべきだ」とか「決心けっしんした以上いじょう、後悔こうかいするな」といった具合ぐあいです。 「は」の有無うむは意味いみに大おおきな違ちがいはありませんが、「は」を付つけると前項ぜんこうの条件じょうけんや前提ぜんていをわずかに強調きょうちょうする語気ごきになります。

「～以上 / ～以上は」の後項こうこう内容ないようは、通常つうじょう前項ぜんこう条件じょうけんに対たいする合理的ごうりてきな結論けつろん、果はたすべき義務ぎむ、あるいは堅かたい決意けついなどです。

【接續】

  • 動詞どうしの普通形ふつうけい (現在形げんざいけい・過去形かこけい) + 以上 / 以上は
    （例れい：するする + 以上、したした + 以上）
  • い形容詞いけいようしの普通形ふつうけい + 以上 / 以上は
    （例れい：新あたらしい + 以上）
  • な形容詞なけいようしである + 以上 / 以上は
    （例れい：必要ひつようである + 以上）
  • 名詞めいしである + 以上 / 以上は
    （例れい：学生がくせいである + 以上）

【例文】

  • 一度いちど引ひき受うけた以上いじょうは、責任せきにんを持もって最後さいごまでやり遂とげます。
    （既然已經接下了，我就會負起責任，直到最後完成。）
  • 彼かれが「やる」と言いった以上いじょうは、必かならずやってくれるだろう。
    （既然他說了「會做」，那他就一定會做到吧。）
  • 大人おとなである以上いじょうは、自分じぶんの行動こうどうに責任せきにんを持もつべきだ。
    （既然是大人了，就應該對自己的行為負責。）
  • 一度いちど決きめた以上いじょうは、どんな困難こんなんがあっても諦あきらめない。
    （既然已經決定了，無論遇到什麼困難都不會放棄。）
  • 部長ぶちょうに相談そうだんした以上いじょうは、彼かれの指示しじに従したがうべきだ。
    （既然已經和部長商量過了，就應該遵從他的指示。）
  • 日本にほんに住すむ以上いじょうは、日本にほんのルールに従したがわなければならない。
    （既然住在日本，就必須遵守日本的規矩。）

【易混淆文法比較】

【～以上 / ～以上は】 vs 【～からには】

這これら2つの文法ぶんぽうは両方りょうほうとも「既然きぜん...，就...」の意味いみを表あらわしますが、語気ごきに若干じゃっかんの違ちがいがあります。「～以上 / ～以上は」は、より客観的きゃっかんてきな事実じじつや既定きてい条件じょうけんに焦点しょうてんを当あて、その事実じじつから当然とうぜんの結果けっかを導みちびき出だします。 一方いっぽう、「～からには」は、より強つよい主観的しゅかんてきな約束やくそく、決意けつい、あるいは義務ぎむの語気ごきを含ふくみ、通常つうじょうは話者わしゃ自身じしんの判断はんだんや責任せきにんを表あらわします。

文法ぶんぽう 語気ごきと重点じゅうてん 例句れいぶん
～以上いじょう / ～以上いじょうは 客観的きゃっかんてき事実じじつ、既定きてい条件じょうけんにおける必然的ひつぜんてき結果けっか。 約束やくそくした以上いじょうは、守まもるべきだ。
（既然約定好了，就應該遵守。）
～からには 主観的しゅかんてきな約束やくそく、決心けっしん、義務ぎむ。 約束やくそくしたからには、必かならず守まもります。
（既然約定好了，就一定會遵守。）

【～以上】（數量すうりょう、程度ていど）

「～以上いじょう」は、上述じょうじゅつの「既然きぜん...，就...」の文法ぶんぽう用法ようほうの他ほかに、数量すうりょう、程度ていど、範囲はんいなど「～を超こえる、～の上うえに」という意味いみでも用もちいられます。
これは、N2文法点ぶんぽうてんとしての「既然きぜん...，就...」の構文こうぶんとは異ことなる、より基礎的きそてきで広範こうはんな用法ようほうです。
例れいえば「30歳以上さいいじょう」（30歲以上さいいじょう）、「これ以上いじょう」（到此為止、不再更多）などです。

  • この仕事しごとは経験けいけんが3年以上ねんいじょうある人ひとが応募おうぼできます。
    （這份工作有三年以上經驗的人可以應徵。）
  • これ以上これいじょうの値上ねあげは、勘弁かんべんしてください。
    （請不要再漲價了。）
