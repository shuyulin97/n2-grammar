N2文法135「〜ないことはない・〜ないこともない」並非不...；也不是不...

【意味】

【解說】

「〜ないことはない」與「〜ないこともない」皆為雙重否定的句型，用以表達一種委婉、消極或有條件的肯定。字面意思是「並非沒有...這回事」，實際語感接近中文的「也不是不...」、「倒也不是不能...」。

這種句型通常不單獨使用，後方常會接著逆接的助詞如「が」或「けど」，來說明之所以無法爽快地、百分之百地肯定的原因、條件或限制。

語氣傾向：
此文法帶有消極、保留、猶豫的語氣。當說話者不想或不能直接、強烈地表示「是」或「可以」時使用。例如，當被問及是否能做某事時，若回答「できます」，聽起來非常肯定且有自信；但若回答「できないことはない」，則暗示「雖然可以做到，但可能很困難、需要特定條件、或者我不太情願」。因此，它通常用於中性或偏向負面的情境，傳達一種「勉強可以」的感覺。

【解說】

從日本的學校文法（國文法）角度來看，「〜ないことはない」的結構是由「否定助動詞 + 形式名詞 + 係助詞 + 形容詞（或助動詞）」組成的。

以「食たべないことはない」為例：

  1. 食たべない：這是動詞「食たべる」的未然形「食べ」接上否定助動詞「ない」。
  2. こと：這是一個形式名詞，它將前面的整個「食べない」這個否定的行為或狀態名詞化，變成「不吃這件事」。
  3. は／も：這是係助詞。「は」用來提示主題，有強調的意味；「も」則帶有「同樣也」的語氣，使語氣更加柔和、委婉，暗示這只是眾多可能性之一。
  4. ない：此處的「ない」是作為一個獨立的形容詞（或看作否定助動詞的終止形），用來否定前面的「〜こと」。

因此，整個句子的字面結構是「『不做某事』這件事，是『沒有』的」，透過雙重否定（二重否定），產生了一種弱肯定的效果。

【使用注意事項】

  • 後句多半會伴隨逆接條件：如前述，因為這是一種有保留的肯定，所以句子後面經常會跟著「〜が」、「〜けど」、「〜ものの」等，來補充限制、困難或不情願的理由。
  • 「〜ないことはない」VS「〜ないこともない」：「〜ないことはない」的語氣稍微直接、肯定一些；而「〜ないこともない」因為助詞「も」的關係，聽起來更加委婉、猶豫，暗示「那樣的可能性也是有的（但也還有別的）」。

【接續】

【動詞】

  • 動詞ない形 + ことはない／こともない
    （文法上是動詞的未然形 + 助動詞ない）
    例：話はなす → 話はなさない → 話はなさないことはない

【い形容詞】

  • い形容詞詞幹 + くない + ことはない／こともない
    例：美味おいしい → 美味おいしくない → 美味おいしくないことはない

【な形容詞】

  • な形容詞詞幹 + ではない + ことはない／こともない
    例：静しずかだ → 静しずかではない → 静しずかではないことはない

【名詞】

  • 名詞 + ではない + ことはない／こともない
    例：無理むりだ → 無理むりではない → 無理むりではないことはない

【例文】

  • この夢ゆめを叶かなえられないことはないけど、そんなに簡単かんたんではない。
    （也不是說無法實現這個夢想，但並不是那麼簡單。）
  • お酒さけは飲のめないこともないですが、一杯いっぱいで顔かおが赤あかくなってしまいます。
    （酒倒也不是不能喝，只是一杯臉就會變紅。）
  • 今いまから走はしれば、最終さいしゅうの電車でんしゃに間まに合あわないこともないかもしれない。
    （如果現在開始跑，或許也不是趕不上末班電車。）
  • このレストランのラーメン、美味おいしくないことはないんだけど、値段ねだんがちょっと高たかすぎるね。
    （這家餐廳的拉麵，也不是說不好吃，但就是價格有點太貴了。）

【易混淆文法比較：「〜ないことはない」vs「〜わけではない」】

【解說】

「〜ないことはない」和「〜わけではない」都帶有否定的意味，但否定的角度和語氣完全不同。「〜ないことはない」是透過雙重否定來達成「弱肯定」，而「〜わけではない」則是對某個推論或前提進行「部分否定」。

文法句型核心差異／使用限制
〜ないことはない【弱肯定】
透過雙重否定，表達「並非完全不可能」、「勉強可以做到」的語氣。重點在於肯定某件事的可能性，即便這種可能性很小或帶有條件。
例：納豆なっとうは食たべないことはない。（意思是「會吃」，但可能不喜歡或不常吃。）
〜わけではない【部分否定／澄清】
用來否定或澄清某個根據當前狀況容易產生的推論。意思是「並不是說...」、「並非...」。重點在於否定一個錯誤的推論或普遍看法。
例：納豆なっとうが嫌きらいなわけではない。（意思是「並不是討厭納豆」，而是可能有其他不吃的原因，例如今天不想吃。）

【情境應用】

假設朋友問你：「你完全不喝酒嗎？」

  • ✅ 飲のめないことはないけど、弱よわいんです。
    （也不是不能喝，只是酒量很差。）
    → 這裡你想表達「能喝」這個事實，但有限制。使用「〜ないことはない」是正確的。
  • ❌ 飲のめるわけではないけど、弱よわいんです。
    （這句話語意不通。「並不是說我能喝，但是我酒量差」邏輯矛盾。）

假設你沒吃桌上的蛋糕，朋友以為你討厭吃甜食。

  • ❌ 甘あまいものが嫌きらいではないことはないです。
    （這句話的意思變成「我不是不討厭甜食」，也就是「我討厭甜食」，與想表達的意思相反。）
  • ✅ 甘あまいものが嫌きらいなわけではないんです。
    （我並不是討厭甜食喔。）
    → 這裡你想澄清「沒吃蛋糕 ≠ 討厭甜食」這個推論。使用「〜わけではない」是正確的。
