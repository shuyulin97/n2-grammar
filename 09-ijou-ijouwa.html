N2文法09「～以上 / ～以上は」既然...就必須... / 既然是...就該...

【意味1】

既然...就必須... / 既然...就該... (因為有了某個前提或條件，所以自然會產生某個結果或義務)

【解說】

「～以上 / ～以上は」表示「既然出現了某個條件、情況，那麼根據這個條件或情況，理所當然會導出後項的結果、義務或判斷」。可以理解為「～なのだから、当然～だ」或「～という状況なのだから、～であるべきだ」的意思。

這個文法強調前項是一個不容改變的前提或事實，後項的內容則是基於這個前提所引申出來的必然結果或應盡的義務。它常常帶有「都已經是這樣了，就沒辦法改變，所以只好...」的語氣，或是一種強烈的勸告、主張。句尾通常接有「～べきだ」、「～なければならない」、「～ほうがない」、「～はずだ」、「～だろう」等表示義務、推測、判斷的表達。

「～以上は」比「～以上」語氣更為強調，常用於較為正式的場合，明確地指出前提條件。

【接續】

  • 動詞：終止形（辞書形）＋ 以上 / 以上は
    例：やる以上
  • い形容詞：終止形＋ 以上 / 以上は
    例：正しい以上
  • な形容詞：語幹＋である＋ 以上 / 以上は
    例：暇である以上
    （亦可接 語幹＋な＋ 以上 / 以上は，如：暇な以上）
  • 名詞：＋である＋ 以上 / 以上は
    例：学生である以上

【例文】

  • 約束やくそくした以上は、守まもるべきだ。
    （既然已經約定了，就應該遵守。）
  • 彼かれが来こないと言いった以上、もう待まつ必要ひつようはないだろう。
    （既然他說不來了，就沒有必要再等了吧。）
  • 社員しゃいんである以上、会社かいしゃのルールには従したがわなければならない。
    （既然是公司的員工，就必須遵守公司的規定。）
  • 一度いちどやると決きめた以上は、最後さいごまでやり遂とげよう。
    （既然決定要做一次，就堅持到底吧。）

【意味2】

既然是...就該... (強調某事物本身的性質、身份或程度，並依此判斷或要求後項內容)

【解說】

此用法強調前項所提及的名詞、狀態或程度本身，因此會產生某種判斷或義務。它更接近「～という性質・立場であるから、当然～だ」的語氣，較不著重於「條件成立後的結果」，而是「因為本質是如此，所以理應如此」。

例如：「プロである以上（既然是專業人士），就應該有專業的態度」。此處的「プロ」是一種身份和性質，由此引申出「專業態度」這種理所當然的要求。

【接續】

  • 名詞：＋である＋ 以上 / 以上は
    例：プロである以上
  • 動詞：終止形（辞書形）＋ 以上 / 以上は
    例：生きている以上

【例文】

  • 大人おとなである以上、自分じぶんの行動こうどうには責任せきにんを持もつべきだ。
    （既然是成年人，就應該對自己的行為負責。）
  • 親おやである以上、子供こどもの安全あんぜんを守まもるのは当然とうぜんのことだ。
    （既然是父母，保護孩子的安全是理所當然的。）
  • 人間にんげんである以上、誰だれでも過あやまちはある。
    （既然是人，誰都會犯錯。）

【易混淆文法比較】

「～以上 / ～以上は」與「～からには」兩者都表示「既然～，就...」，常用於表達既然做了某事或處於某種狀態，就應當做後項的動作或承擔後項的結果。兩者很多情況下可以互換使用，但在語氣上仍有些微差異。
