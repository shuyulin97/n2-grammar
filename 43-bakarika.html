N2文法43「〜ばかりか」不但...而且...

【意味】

解說

核心意思是「不但～，而且連～也～」。用來表示不僅僅是前項（A）的程度，甚至還有更進一步的後項（B）情況。前後項可以是同方向的遞進，例如「不但好，而且更好」；也可以是不同方向的補充，例如「不但成績好，運動也很擅長」。

語氣上，「〜ばかりか」帶有較強的意外或驚訝感，強調後項（B）的內容是超乎預期的。因此，後項（B）的內容通常比前項（A）更具份量或更令人驚訝。這個句型在正面和負面的情境中都可以使用。

【解說】

文法結構

「〜ばかりか」是由三個部分組成的複合助詞，在文法上被視為「接続助詞（せつぞくじょし）」，用來連接兩個子句。

  • ばかり：此處為「副助詞」，帶有「限定（只有、光是）」的語感。
  • か：此處為「係助詞」，帶有「反問、強調」的語氣。

兩者結合在一起，字面上的感覺就像是「難道光是這樣而已嗎？（不，還有更多）」，從而衍生出「不但...而且...」的遞進意思，並隱含著對後項內容的驚訝與強調。

使用注意事項

  • 後項（B）經常伴隨著「も」、「さえ」、「まで」等助詞來加強語氣。
  • 「〜ばかりか」主要用來陳述事實或狀態，因此後句一般不接續說話者的意志、命令、請求、勸誘等主觀表現。
  • 相較於「〜だけでなく」，「〜ばかりか」的語氣較為正式、生硬，常出現在書面語或較正式的發言中。

【接續】

動詞

  • 動詞普通形（Vる / Vた / Vない / Vなかった） + ばかりか
  • 原理：此處的「ばかり」接在用言（動詞、形容詞）的「連体形（れんたいけい）」之後。在現代日語中，動詞的連体形與終止形（普通形）相同。

名詞

  • 名詞 + ばかりか
  • 名詞 + である + ばかりか
  • 原理：名詞可以直接連接。在較正式的文體中，為了使語氣更完整，有時會在名詞後面加上「である」。

形容詞

  • い形容詞 + ばかりか
  • 原理：い形容詞的連体形與終止形相同，直接連接即可。
  • な形容詞 + な / である + ばかりか
  • 原理：な形容詞的連体形為「〜な」，因此用「な」來連接。也可以使用「である」的形式。

【例文】

  • 彼かれの家いえは駅えきから遠とおいばかりか、坂道さかみちも多くて大変たいへんだ。
    （他家不只離車站很遠，而且坡道也很多，非常辛苦。）

  • このレストランは料理りょうりが美味おいしいばかりか、店員てんいんのサービスも最高さいこうだ。
    （這家餐廳不僅料理美味，店員的服務也是最棒的。）

  • 山中やまなかで道みちに迷まよった時とき、雨あめが降ふり出だしたばかりか、日ひまで暮くれてしまった。
    （在山裡迷路時，不但開始下雨，甚至天都黑了。）

  • 山田やまださんは日本語にほんごばかりか、スペイン語ごまで話はなせるそうだ。
    （聽說山田先生不僅會日文，甚至連西班牙語都會說。）

【易混淆文法比較：「〜ばかりか」VS「〜だけでなく」】

「〜ばかりか」和「〜だけでなく」中文都可翻成「不只、不但」，但在語感和使用限制上存在差異。

文法句型 核心差異／使用限制
〜ばかりか ・ 語氣較為生硬、書面語。
・ 強調後項的「程度更高、更超乎預期」，帶有驚訝的語氣。
・ 後句多為描述事實，較少接續意志、命令、勸誘等主觀表現。
例：彼かれは漢字かんじが読よめないばかりか、ひらがなさえ書かけない。
（他不只漢字不會讀，甚至連平假名都不會寫。）
〜だけでなく ・ 口語、書面語皆可使用，較為中性、客觀。
・ 僅單純表示「不僅如此，還有...」，添加情報，驚訝語氣較弱。
・ 後句的限制較少，可以接續意志、命令等主觀表現。
例：このレストランは味あじがよいだけでなく、サービスも満点まんてんだ。
（這家餐廳不只味道好，服務也滿分。）

後句接續意志、命令時的差異

「〜ばかりか」因其客觀陳述的特性，不適合用在命令句中。

❌ 野菜やさいばかりか、肉にくも食たべなさい。

✅ 野菜やさいだけでなく、肉にくも食たべなさい。
（不只要吃蔬菜，肉也要吃。）

說明：因為句尾是「〜なさい」的命令形式，表達說話者的要求，所以使用限制較少的「〜だけでなく」才是正確的。
