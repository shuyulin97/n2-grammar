N2文法132「〜に相違ない」肯定是～、一定是～

【意味】

核心意思

表示基於某些客觀事實或根據，說話者非常有自信地做出判斷或結論，相當於中文的「肯定是～」、「一定是～」、「想必是～」。這是一種帶有強烈確信語氣的表達方式。

語氣傾向

「〜に相違ない」是個非常書面、正式且生硬（硬い表現）的說法，常用於新聞報導、評論、論文、判決書等正式場合。日常口語對話中較少使用，若使用會給人一種故作姿態或過於嚴肅的感覺。語氣上是中性的，可以用於正面、負面或客觀陳述，重點在於傳達「基於證據的確信」。

【解說】

文法結構解析

「〜に相違ない」是由名詞「相違（そうい）」、助詞「に」、補助形容詞「ない」所組成。

  • 相違（そうい）：漢字意思是「互相不同」，在文法中作為形式名詞，表示「差異、不一致」。
  • に：格助詞，在此表示比較的基準點。
  • ない：否定助動詞「ぬ」的連体形，或是形容詞「ない」的終止形。

從字面上直譯為「與...沒有差異」，延伸的意思就是「和...完全一致」，因此用來表示「肯定就是...」、「絕對是...」。可以將它視為「〜にちがいない」的更加正式、書面的版本。

使用限制

由於此文法是說話者基於證據所下的斷定，因此有以下限制：

  1. 不描述自身行為：通常不用於描述自己的行為或意志。例如，不能說「私が行くに相違ない（我肯定會去）」。
  2. 基於客觀根據：使用的情境通常伴隨著明確的客觀證據或理由。若只是單純的主觀猜測，使用「〜だろう」或「〜かもしれない」會更自然。
  3. 後句限制：因為是表示斷定的句型，後面通常不接續表示意志、命令、推測的句子。

【接續】

動詞

  • 普通形（終止形・連体形） + に相違ない

  • 說明：動詞以普通形（字典形、た形、ない形等）直接接續。在這裡，動詞的普通形（連体形）修飾著一個被省略的概念，像是「～ということ（...這件事）」，因此可以和「に相違ない」連結。

  • 例：起おきた + に相違ない / 起おきる + に相違ない

い形容詞

  • 普通形（終止形・連体形） + に相違ない
  • 說明：與動詞相同，直接接續即可。
  • 例：忙いそがしい + に相違ない

な形容詞

  • な形容詞語幹 + である + に相違ない
  • な形容詞語幹 + に相違ない
  • 說明：接續な形容詞時，標準且更正式的用法是加上「である」。在某些情況下，「である」可以省略，但加上會讓句子聽起來更完整且鄭重。
  • 例：重大じゅうだいである + に相違ない / 重大じゅうだい + に相違ない

名詞

  • 名詞 + である + に相違ない
  • 名詞 + に相違ない
  • 說明：與な形容詞的接續方式相同。加上「である」是比較正式且完整的用法。
  • 例：事実じじつである + に相違ない / 事実じじつ + に相違ない

【例文】

  • 彼かれは相当そうとう疲つかれているみたいだ。 最近さいきん忙いそがしいに相違そういない。
    （他看起來相當疲憊。最近肯定很忙。）

  • 現場げんばに残のこされた指紋しもんから判断はんだんすると、犯人はんにんは彼かれに相違そういない。
    （從現場留下的指紋來判斷，犯人肯定是他。）

  • 目撃者もくげきしゃの証言しょうげんが一致いっちしていることから、事故じこはここで起おきたに相違そういない。
    （從目擊者的證詞一致這點來看，事故肯定是在這裡發生的。）

  • この芸術げいじゅつ作品さくひんが後世こうせいに与あたえた影響えいきょうは、非常ひじょうに大おおきなものであったに相違そういない。
    （這件藝術作品對後世所帶來的影響，想必是極其巨大的。）

【易混淆文法比較：「〜に相違ない」 vs 「〜にちがいない」】

「〜に相違ない」和「〜にちがいない」都表示「肯定、一定」，但在語氣的正式度和使用場合上有明顯區別。

文法句型 核心差異／使用限制
〜に相違ない 非常正式、書面語。
常用於新聞、論文、法律文件等需要客觀陳述、基於明確證據下判斷的場合。語氣較生硬。
〜にちがいない 通用，口語書面皆可。
使用範圍廣泛，可用於客觀證據，也可用於較強烈的主觀推測。是日常生活中最常用來表達「肯定」的句型。

情境範例

假設在法庭上，檢察官根據證據做出結論：

  • ⭕ 証拠しょうこからみて、彼かれが犯人はんにんであるに相違そういありません。
    （從證據來看，他肯定是犯人。）
    → 在此情境下非常自然、專業。
  • 🔺 証拠しょうこからみて、彼かれが犯人はんにんにちがいない。
    （從證據來看，他一定是犯人。）
    → 雖然文法正確，但在極正式的場合下顯得不夠莊重。

假設看到朋友滿臉笑容，猜測他考試通過了：

  • ❌ あんなに嬉うれしそうな顔かおで、試験しけんに合格ごうかくしたに相違そういない。
    → 語氣過於生硬，非常不自然，像是在寫報告分析朋友的表情。
  • ⭕ あんなに嬉うれしそうな顔かおで、試験しけんに合格ごうかくしたにちがいない。
    （看他那麼開心的樣子，肯定是考試通過了。）
    → 非常自然，符合日常對話情境。

總結來說，可以將「〜に相違ない」視為「〜にちがいない」的上位書面語。在需要展現客觀、嚴謹、正式的場合使用前者，在一般日常溝通中則使用後者。
