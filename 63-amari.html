N2文法63「〜あまり（に）・あまりの〜に・あまりに（も）」太.../過於...

【意味】

表示「程度極端、超出常軌」，進而導致了「某種不尋常、通常是負面的結果」。中文常譯為「因過於...，以致於...」或「太...，結果...」。

此文法帶有強烈的情感色彩或評價。雖然造成的原因本身可以是正面的（如：過於高興），但後項引發的結果多半是超乎預期、難以控制或負面的情況。例如，高興到說不出話、擔心到睡不著等，重點在於「因程度過甚而引發的異常結果」。

【解說】

あまり源自動詞余あまる，意思是「剩餘、過多」。其「連用形（れんようけい）」あまり可作為名詞或副詞使用，這就是此文法的基礎。

  • 〜あまり：此處的あまり作為形式名詞使用。因此，前方必須接「連体形（れんたいけい）」（用來修飾名詞的形態），如動詞的辞書形、た形，或名詞＋の、な形容詞＋な。
  • あまりに（も）：此處的あまり作為副詞使用，用來修飾後方的動詞、形容詞。に是助詞，而も是用於加強語氣，表示「實在是太...」。
  • あまりの〜に：あまり在此作為名詞，加上助詞の後，形成「あまりの」這個「連体詞（れんたいし）」的形式，用來修飾後方的名詞（多為表示情感或狀態的名詞），以強調其程度之高。句尾的に表示原因。

【使用注意】
因為表示「因程度過甚而導致了某種自然發生的結果」，所以後句通常是描述一種狀態或無意識的行為，不可以使用帶有說話者意志、命令、請求、推量或否定的句子。

⭕️ 緊張きんちょうのあまり、声こえが震ふるえてしまった。（自然發生的結果）
（因為過於緊張，聲音都顫抖了。）

❌ 緊張きんちょうのあまり、しっかり話はなそう。（意志）

【接續】

1. 動詞 + あまり
Vる / Vた + あまり
（接續動詞的「連体形」。）

  • 心配しんぱいするあまり、驚おどろいたあまり

2. 名詞 + の + あまり
N の あまり
（主要接續表示情感或狀態的名詞。）

  • 悲かなしみのあまり、緊張きんちょうのあまり

3. な形容詞 + な + あまり
なA な あまり

  • 心配しんぱいなあまり

4. あまりの + 名詞 + に
あまりの N に
（「あまりの」修飾後方名詞，強調其程度之高。）

  • あまりの暑あつさに、あまりの恐怖きょうふに

5. あまりに（も） + 形容詞 / 動詞
あまりに（も） + Aい / なA / V
（作為副詞，修飾後方的用言。）

  • あまりに悲かなしくて、あまりにも驚おどろいて

【例文】

  • 母ははは子供こどもを心配しんぱいするあまり、病気びょうきになってしまった。
    （媽媽因為過於擔心孩子，結果生病了。）

  • 突然とつぜんの悲報ひほうに、彼女かのじょは悲かなしみのあまり、声こえも出でなかった。
    （聽到突如其來的噩耗，她因過於悲傷而說不出話來。）

  • あまりの恐おそろしさに、足あしがすくんで一いっ歩ぽも動うごけなかった。
    （由於太過恐懼，嚇得雙腿發軟，一步也動不了。）

  • その景色けしきはあまりにも美うつくしくて、しばらく言葉ことばを失うしなった。
    （那片景色實在是太美了，讓我一時之間說不出話來。）

【易混淆文法比較：「あまり」vs「～すぎる」】

「あまり」和「すぎる」都表示「程度過甚」，但語感和用法上有明顯區別。

文法句型核心差異／使用限制
〜あまり強調「因程度過甚，而導致了某種超乎預期、難以控制的結果」。
  • 著重在前後的因果關係。
  • 後句多為負面或意料外的結果。
  • 後句不能接意志表現（命令、請求、意向等）。
〜すぎる僅客觀（或主觀）地陳述「程度過量、超過了適當的範圍」。
  • 重點在於描述「過度」這個狀態本身。
  • 後續可以接續各種句子，包含意志表現。

【例文比較】

情境：工作過度

⭕️ 働はたらきすぎたあまり、倒たおれてしまった。
（因為工作過度，結果昏倒了。）
解說：強調「工作過度」是原因，「昏倒」是其導致的負面、非自願的結果。

⭕️ 昨日きのうは働はたらきすぎた。
（昨天工作過頭了。）
解說：僅陳述「工作過度」這個事實。

❌ 働はたらきすぎたあまり、休やすもうと思おもう。
解說：「休もうと思う（想要休息）」是意志表現，不能與「あまり」共用。

⭕️ 働はたらきすぎたから、今日きょうは休やすもうと思おもう。
（因為工作過度，所以今天想休息。）
解說：「すぎる」的句子後面可以接續意志表現。
