N2文法133「〜得る・〜得ない」有可能／不可能

【意味】

核心意思為「有可能（發生）～」、「不可能（發生）～」，用來表達某件事情發生的可能性。

「〜得る（うる／える）」表示可能性存在；而其否定形「〜得ない（えない）」則表示可能性為零，意思接近「絶対に〜ない」。

  • 語氣傾向：這是一個比較生硬、客觀的書面語。主要用於中性的陳述，不帶有強烈的情感色彩。然而，「〜得ない」在某些情境下，可以表達出強烈的否定、懷疑或批判，例如「信じ得ない（難以置信）」、「許し得ない（不可原諒）」。
  • 補充：在現代日語中，否定形式「〜得ない」的使用頻率遠高於肯定形式「〜得る」。

【解說】

從學校文法（國文法）的角度來看，「得る（える）」是一個下二段活用動詞，但在這個句型中，它作為「補助動詞」接在其他動詞後面，為前方的動詞增添「可能性」的含意。

它連接在動詞的「連用形」後面。連用形也就是我們常說的「ます形去掉ます」的形式。

關於「得る」的讀音，有兩種：

  • うる (uru)：用於「終止形」（句尾）與「連體形」（修飾名詞時）。這是比較傳統、正式的讀法。
  • える (eru)：同樣用於「終止形」與「連體形」。這是現代比較普遍的讀法。

例如，「起こるかもしれない」可以說成「起こり得る」，讀音可以是「おこりうる」或「おこりえる」。兩者意思相同，但「うる」的語感更為正式、傳統。

【重要】否定形一律讀作「〜得ない（えない）」，沒有「〜得ない（うない）」的說法。

【使用限制】

此文法最大的限制是，它只表示「狀況上的可能性」，而不表示「個人的能力」。因此，不能用來表達像「我會游泳」、「我會說日文」這類的能力。

例如：想表達「我會開車」，不能說「私は運転し得る」。

此外，這個文法沒有意志形或命令形。它僅用於客觀陳述可能性。

【接續】

  • 動詞： 動詞連用形（ます形去掉ます） + 得る／得ない

範例：

  • 考かんがえます → 考かんがえ + 得る → 考かんがえ得うる
  • あり　ます → あり + 得ない → あり得えない
  • 信しんじます → 信しんじ + 得ない → 信しんじ得えない

【例文】

  • 今いま考かんがえ得うるすべての方法ほうほうを試ためしてみましょう。
    （讓我們試試看現在所有能想到的方法吧。）

  • あんな真面目まじめな彼かれが人ひとを裏切うらぎるなんて、あり得えない話はなしだ。
    （像他那麼認真的人會背叛他人，這是不可能的事。）

  • 今回こんかいの事故じこは、十分じゅうぶんに予測よそくし得えたはずだ。
    （這次的事故，照理說是完全可以預測到的。）

  • この不況ふきょうでは、有名ゆうめい企業きぎょうでも倒産とうさんし得うる。
    （在這樣不景氣的環境下，即使是知名企業也有可能倒閉。）

【易混淆文法比較：「〜得る」vs「可能形 / 〜ことができる」】

「〜得る」和「可能形（〜れる／られる）」或「〜ことができる」雖然都和「可能」有關，但核心語意完全不同。前者表示「狀況或邏輯上的可能性」，後者則表示「個人的能力或許可」。

文法句型核心差異／使用限制
〜得る／得ない表示狀況或邏輯上的「可能性」。
・屬於書面語，語氣較生硬。
・多用於討論抽象事物、預測或理論上的可能性。
・主語常常是事物或狀況（例：事故、問題、理論）。
・不表示個人能力。
可能形 / 〜ことができる表示個人的「能力」或外界條件的「許可」。
・口語、書面語皆可廣泛使用。
・可用於具體、個人的行為。
・主語常常是人。

【錯誤用法 ❌】

以下情境強調「個人能力」，因此不能使用「〜得る」。

  • ❌ 私わたしは納豆なっとうを食たべ得る。
    （想表達「我敢吃納豆」，這屬於個人能力或習慣。）

  • ✅ 私わたしは納豆なっとうが食たべられる。／納豆なっとうを食たべることができる。
    （我會吃納豆。）

【正確用法 ✅】

以下情境描述「事情發生的可能性」，因此使用「〜得る」是自然的。

  • ✅ どんな人間にんげんでも間違まちがいを犯おかし得る。
    （無論是誰，都有可能犯錯。→ 描述一種普遍的可能性，而非特定某人的能力。）

  • ⚠️ この問題もんだいは簡単かんたんだから、子供こどもでも解とくことができる。
    （這個問題很簡單，所以連小孩子都能解開。→ 描述小孩子具備解題的能力。）
